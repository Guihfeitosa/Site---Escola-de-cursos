# GHS - Cursos

Site de uma escola de cursos de tecnologia, feito como atividade de informática.

## Como abrir

Abra o arquivo `index.html` no navegador. Use o menu para acessar as páginas de cursos, professores e contatos. O menu também funciona em telas pequenas.

## Arquivos

- `index.html`: página inicial.
- `curso.html`: cursos e categorias.
- `professores.html`: apresentação do professor.
- `contatos.html`: formas de contato.
- `usuarios.html`: endereço antigo que leva à página de professores.
- `css/styles.css`: estilos do site.
- `js/main.js`: funcionamento do menu.
- `img/`: imagens que já estavam no projeto.

Os contatos da página são exemplos do projeto e devem ser confirmados antes do uso. O link de e-mail abre o aplicativo de e-mail do dispositivo; o site não envia mensagens por conta própria.
